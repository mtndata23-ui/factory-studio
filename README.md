# Factory Studio

Factory Studio is a Rust rewrite and extension of **IngeTrazo** (https://github.com/ingelibre/ingetrazo), developed by mtndata23-ui.

The goal is to move the IngeTrazo core (file I/O, mesh, push/pull, offset, intersect, BIM/IFC) to Rust step by step, proving each part gives the same results as the original Python engine, then add factory-layout features.

Status: work in progress. Source code will be uploaded soon.
